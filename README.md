# Random Scripts

Small, reusable scripts. See each folder for instructions.

- [WAV compression](wav-compression/README.md): Convert a directory of WAV recordings to AAC/M4A or lossless FLAC, verify the outputs, and optionally create an upload ZIP.
- [Tax return check](tax-check/README.md): Double-check a prepared 2025 federal tax return against your W-2s and 1099s with a local model. Nothing leaves your computer.

No recordings, tax documents, reports, or credentials belong in this repository.
